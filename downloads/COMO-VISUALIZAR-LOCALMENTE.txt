COMO VISUALIZAR SEM PUBLICAR

Este pacote contém o site mais recente, o código-fonte e as instruções de configuração.

OPÇÃO RECOMENDADA: VS CODE + LIVE SERVER
1. Instale o Visual Studio Code: https://code.visualstudio.com/
2. No VS Code, abra Extensões (Ctrl+Shift+X), procure Live Server (autor Ritwick Dey) e instale.
3. Extraia este ZIP. No VS Code, use Arquivo > Abrir Pasta e escolha especificamente a pasta dist que está dentro de site-cecilia. Não abra a pasta principal para este método.
4. Na lista de arquivos, clique com o botão direito em index.html e escolha Open with Live Server.
5. O navegador abrirá uma URL local, normalmente http://127.0.0.1:5500. O site não está publicado na internet.

ALTERNATIVA COM PYTHON INSTALADO
Abra um terminal na pasta site-cecilia e execute:
python -m http.server 8000 --bind 127.0.0.1 --directory dist
Depois abra http://127.0.0.1:8000. No Windows, você pode usar py no lugar de python.

LIMITES DESTA PRÉVIA
Não abra index.html diretamente com duplo clique: o site precisa do servidor local.
Os botões Vamos conversar abrem a janela de contato. Nela, o link de e-mail abre seu aplicativo para escrever para cecilia.vetchi@gmail.com; o link do direct abre https://ig.me/m/cecilia.vetchi e pode pedir login no Instagram. Isso também funciona em uma prévia local se houver um aplicativo de e-mail configurado.
Não há formulário ou dependência do Netlify Forms. Nenhum e-mail é enviado automaticamente pelo site.
Links externos precisam de internet; os dois botões do Spotify já usam o endereço oficial fornecido.
